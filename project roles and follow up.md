# Smart Classroom Energy Management System

## 🧠 Project Description in Brief

### 1. Name of the Project
**Smart Classroom Energy Management System**

### 2. Goal of the Project
The goal of this project is to design and implement an **IoT-based energy management system** that automatically monitors and controls classroom electrical devices such as lights, fans, and air conditioners.  
The system aims to **reduce energy waste** by detecting human presence, light levels, and room temperature, while allowing **remote monitoring and control** through a mobile app or web interface.

### 3. Hardware Used in the Project
- **Arduino UNO** – Main microcontroller for device control  
- **Arduino WiFi Rev2** – Provides wireless IoT connectivity  
- **PIR Motion Sensor (HC-SR501)** – Detects occupancy in the classroom  
- **LDR (Light Dependent Resistor)** – Detects ambient light level  
- **DHT11 Sensor** – Measures temperature and humidity  
- **4-Channel Relay Module** – Controls lights, fans, or AC units  
- **Power Supply (5V/12V)** – Powers the Arduino and relays  
- **Breadboard and Jumper Wires** – For circuit connections  
- *(Optional)* **OLED Display (0.96” I2C)** – Displays sensor readings

## ⚠️ Risks and Uncertainties

### 1. Current Uncertainties
- **Wi-Fi connection stability** inside campus buildings  
- **Sensor accuracy** in different classroom environments  
- **Power supply interruptions** during testing  
- **Delay in component delivery** if replacements are needed  
- **Integration issues** between hardware and IoT cloud platform  

### Risk Mitigation
- Backup offline mode (manual switch control)  
- Test multiple Wi-Fi hotspots  
- Calibrate sensors before deployment

## ✅ Expected Outcome
A functional IoT-based prototype capable of:
- Monitoring classroom conditions (light, motion, temperature)  
- Automatically turning off devices when no one is present  
- Displaying real-time data and allowing remote control via a mobile app  

This project demonstrates how **IoT and automation** can improve **energy efficiency and sustainability** in educational environments.
